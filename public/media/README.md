Optional local assets go here.

- Add a licensed H2R audio recording as `h2r.mp3`, then set
  `ENGINE_AUDIO_URL = "/media/h2r.mp3"` in `app/page.jsx`.
- Replace the six external `IMAGES` URLs with unique `/media/*.webp` paths to use
  licensed self-hosted photos. Never point two image keys at the same photograph.

No local media files are required for the included synthesized sound demo or
external image placeholders.
